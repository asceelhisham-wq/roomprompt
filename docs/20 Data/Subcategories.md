# Subcategories

Every piece belongs to one category and one subcategory. Picking a category chip shows a second row of subcategory chips with counts; the library then groups by subcategory.

Defined in `SUBCATEGORIES` in `src/data.js` as `[id, name, "base ids…"]`. `check.js` fails the build check if any piece is left without one.
